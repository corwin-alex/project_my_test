# Онлайн-тестирование

Веб-приложение для проведения онлайн-тестирования студентов.

## Стек технологий

- **Frontend**: React, React Router, Bootstrap, SCSS
- **Backend**: Node.js, Express.js
- **База данных**: PostgreSQL
- **Сборка**: Webpack

## Возможности

### Для администратора:
- Создание и редактирование тестов
- Добавление вопросов с вариантами ответов
- Просмотр результатов всех студентов
- Управление статусом тестов (активен/неактивен)

### Для студента:
- Прохождение доступных тестов
- Автоматическая оценка результатов
- Просмотр своих результатов

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd online-testing-app
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и настройте значения:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл, указав ваши параметры подключения к базе данных и другие настройки.

### 4. Создание базы данных

Создайте базу данных PostgreSQL с именем, указанным в `.env`:

```sql
CREATE DATABASE online_testing;
```

Таблицы создадутся автоматически при первом запуске сервера.

### 5. Запуск приложения

#### Режим разработки

Запуск сервера и клиента отдельно:

```bash
# Терминал 1 - сервер
npm run dev:server

# Терминал 2 - клиент (Webpack Dev Server)
npm run dev:client
```

Сервер будет доступен на `http://localhost:3000`, клиент на `http://localhost:3001`.

#### Продакшен сборка

```bash
# Сборка фронтенда
npm run build

# Запуск сервера (раздает статические файлы из public/)
npm start
```

## API Endpoints

### Авторизация
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Вход пользователя

### Тесты
- `GET /api/tests` - Список всех тестов
- `GET /api/tests/:id` - Детальная информация о тесте
- `POST /api/tests` - Создать тест (админ)
- `PUT /api/tests/:id` - Обновить тест (админ)
- `DELETE /api/tests/:id` - Удалить тест (админ)

### Вопросы и ответы
- `POST /api/questions/questions` - Добавить вопрос (админ)
- `POST /api/questions/answers` - Добавить ответ (админ)

### Результаты
- `POST /api/results/start` - Начать тестирование (студент)
- `POST /api/results/complete` - Завершить тестирование (студент)
- `GET /api/results/my-results` - Мои результаты (студент)
- `GET /api/admin` - Все результаты (админ)

## Деплой на Render

1. Создайте новый Web Service на Render
2. Подключите ваш репозиторий
3. Добавьте переменные окружения из `.env.example`
4. Создайте PostgreSQL базу данных через Render
5. Используйте команды:
   - Build: `npm install && npm run build`
   - Start: `npm start`
